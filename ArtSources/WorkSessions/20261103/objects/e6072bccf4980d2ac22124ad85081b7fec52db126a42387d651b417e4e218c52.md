# Portable Fabius Normal essentials staging

This package contains only 16 Parry/Hurt/Dead atlases (72 clips, 144 frames), their descriptors, and exact technical-source PNG copies. It excludes all Walk sheets, including Moto Walk after direct rejection of the long-legged version.

Rerun from any working directory with Python 3.10+ and Pillow 10+: `python prepare_portable_essentials.py --root <project-checkout> --out .`. The script refuses an output directory inside the project root. It reads the checkout and writes only this external output package.

The 13 atlases without overlaps are copied byte-for-byte. Three Hurt atlases are packing-only derivatives: the full original canvas is retained at the top-left; exact full-frame RGBA crops are copied below it into disjoint rectangles with 2px gutters. Sprite frame IDs, crop dimensions, pivots, PPU, frame PPU, durations, timing, loop, and guardContact metadata are unchanged. sourceRect/sourceFrameIndex records each pre-repack crop. No pixel was removed, resized, resampled, recolored, or composited.

`ArtSources/ReviewedDeliveries/FabiusNormal20261103/staging/technical-source/` contains byte-exact copies of the reviewed native atlas PNGs. The new descriptors bind sourcePath/sourceSha256/sourceSize to those technical copies. `provenance.originalAuthoredSource` preserves the historical authored-source path/hash/size and marks `rawSourceAvailable:false`; exact reviewed-atlas hash matches are reported separately. This does not claim recovery of a distinct generator source or approve runtime use.

Status remains static visual review of original pixels. Packing proof is separate. Package PAGES remains `complete:false`; no Unity importer, Assets write, runtime test, gameplay test, or new art was performed.
