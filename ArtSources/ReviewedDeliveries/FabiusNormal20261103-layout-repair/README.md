# Fabius Normal — lossless atlas layout repair

Three Hurt atlases had overlapping sprite rectangles. LayoutV2 repacks 24 complete figures without changing RGBA pixels, local dimensions, pivots, PPU, frame IDs or timings. Original sources and prior delivery remain preserved. The tools reject overlapping rectangles before opening Unity and retain superseded deliveries as history.

Local Unity receipts now cover all 167 session clips / 492 figures / 52 active sheets. Three current isolated PlayMode tests cover only the original 15 clips; this does not approve the entire delivery, campaign, guard sparks or build. Fists SW and Moto W/E walks remain unfinished. This archive publishes source layouts and tooling, not game runtime or a Windows build.
