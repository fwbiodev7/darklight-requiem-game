# Portable reviewed Walks: Katana + Fists

Six reviewed archive PNGs, nine Normal clips, 36 frames. This bundle contains Katana directions NE/E/SE and Fists directions N/NW/E/NE/SE/W. Moto Walk is explicitly excluded: the lateral V3 is approved and the six remaining directions are under another agent's correction.

All six archived atlas PNGs are copied byte-for-byte into `staging/` and as technical source copies under `ArtSources/ReviewedDeliveries/FabiusNormal20261103/staging/technical-source/`. Descriptors and PAGES bind to those technical copies. The old authored-source path/hash/dimensions remain in `provenance.originalAuthoredSource` with `rawSourceAvailable:false`; there is no claim that an absent raw generator source was recovered. Four source hashes equal the reviewed atlas hash; two differ.

Rectangles are in bounds, non-overlapping, and frame crops reproduce exactly because the atlas bytes are unchanged. Sprite IDs, pivots, PPU/frame PPU, durations, loop, and all other page timing fields are preserved. The static Unity `VerifySheet`/`ValidPage` shape checks passed. `PAGES.complete` remains false; no Unity, Assets write, runtime test, or gameplay approval was performed.

Rerun from anywhere with Python 3.10+ and Pillow 10+: `python prepare_reviewed_walks.py --root <checkout> --out .`. Output must be outside the checkout. The routine hashes only the six selected atlas source PNGs and writes only this package.
