# Clipes reais do Cavaleiro — após a publicação Beta5

Capturados no Unity URP2D com o runtime publicado, skin Rock normal e entradas de teclado simuladas. Figuras completas, hitboxes e inimigo reais; nenhum áudio reproduzido. Não são animações montadas a partir de sprites importados.

- [Serras — MP4](serras-combo.mp4) · [GIF](serras-combo.gif):120 quadros,5 poses, dano74,765625 no alvo de teste.
- [Moto, derrapagem e retorno ao combo — MP4](moto-derrapagem-retorno.mp4) · [GIF](moto-derrapagem-retorno.gif):120 quadros,14 poses, montagem/derrapagem/salto/novo ataque confirmados, dano43.
- [Esmagamento — MP4](moto-esmagamento.mp4) · [GIF](moto-esmagamento.gif):72 quadros,5 poses, dano38.

MP4:1280×720/30FPS; GIF:960×540/20FPS. A simulação foi fixada em30FPS para captura; não usar esses clipes como benchmark de desempenho ou avaliação humana. A arena recarrega sangue intencionalmente, portanto o custo dos ataques é verificado pelos testes separados. Hashes, contagens e evidências no [manifesto](manifest.json).

Os quadros de pernas transformadas em revisão não foram usados nestes clipes.
